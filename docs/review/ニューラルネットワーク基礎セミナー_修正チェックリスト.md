## 総評

インフォグラフィックの表現力は高く、「学習率＝谷を下る歩幅」「6を180°回転すると9になる」など、非エンジニアへの説明として秀逸な比喩が多く含まれている。

## 🔴 登壇前必須（2件）

### 1. S7「ニューロン1個の仕組み」— 計算結果が誤り

```
0.8 × 0.9 + 0.2 × 0.4 + 0.5 × 0.6 + 0.1（バイアス）
= 0.72 + 0.08 + 0.30 + 0.10
= 1.20   ← 正しい値
スライド上の表記は「1.16」  ← 誤り
```

- [ ] Σ → 活性化関数の矢印ラベル `1.16` を `1.20` に
- [ ] 「計算の流れ（例）」の `= 1.16` を `= 1.20` に
- [ ] `ReLU(1.16) = 1.16（そのまま出力）` を `ReLU(1.20) = 1.20` に（2箇所）
- [ ] 右端オレンジ円の出力値 `1.16` を `1.20` に

> ⚠️ スライド全体が1枚のPNG画像として焼き込まれているため、**元画像の再生成が必要**。

### 2. S3「本セミナーの目的」— 因果関係の誤り

> ニューラルネットワークの学習手法である「誤差逆伝播法」と、**その弊害となる**過学習の対処法を学び

過学習は誤差逆伝播法の弊害ではない。S18で自ら挙げている原因（学習データが少ない／モデルが大きすぎる／学習させすぎる）のいずれも誤差逆伝播法ではなく、**資料内で矛盾している**。

- [ ] 「その弊害となる過学習」→「**学習を進める際に生じる**過学習」に修正

## 補足：本編が画像化されていることの影響

スライド6-20は全面1枚のPNG（各約1.5MB）で構成されており、以下の実害を生んでいる。

| 影響 | 内容 |
| --- | --- |
| 修正コスト | No.1「1.16→1.20」の修正がPowerPoint上で不可能。画像の作り直しが必要 |
| アクセシビリティ | 代替テキスト未設定でスクリーンリーダー読み上げ不可 |
| 再利用性 | 検索・翻訳・コピーが不可 |
| 可読性 | 1672×941px。プロジェクタ解像度によっては小さい注釈が判読困難 |
| 配布性 | ファイルサイズ30.7MBでメール添付が困難 |

最低限、**代替テキストの設定**と**画像の圧縮**を推奨。今後の資料作成では、図版のみを画像化し、テキストはPowerPointのテキストボックスで持つ構成が望ましい。
