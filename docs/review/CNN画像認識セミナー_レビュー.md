## 🔴 重大（開催前に要修正）

内容の矛盾・数値の誤り・記述リスク。指摘されると資料全体の信頼を損ないます。

### [ ] 1. S11 — 畳み込みの計算例が数学的に成立していない

入力は 4×4（全行 `1 1 9 9`）、フィルタは 3×3。ストライド1・パディングなしなら **出力は 2×2** で、しかも全行が同一パターンのため **有効な窓はすべて 24** になります。

- スライド上の出力は 4×4 で `24 24 0 0 / 24 24 0 0 / 24 24 0 0 / 0 0 0 0`
- 「3回目 → 0」は、4列の入力に3列の窓では **そもそも3番目の横位置が存在しない**

> **対応案**: 入力を 6×6 程度に拡張し、右端に暗い列を戻して 0 や負値が自然に出る形にする。または出力を 2×2（全て24）にして「4×4入力＋3×3フィルタ → 2×2出力」とサイズ縮小の説明を足す。受講者が実際に手計算で追う箇所です。

### [ ] 2. S17 — 「転移学習が向いているケース」がS18と矛盾している

- **S17** →「**転移学習**が向いているケース：十分なデータがある／より高い精度／ドメインが大きく異なる」
- **S18** → **同じ3項目** が「**ファインチューニング**が向いているケース」

正しいのはS18側です。S17はタイトルが「ゼロから学習 vs 転移学習」なのに、下段まとめ（「なぜ違いが生まれるのか？」ブロックを含む）がS18からの丸ごとコピーになっています。

> **対応案**: S17の下段を「ゼロから学習が向くケース／転移学習が向くケース」に差し替える。

### [ ] 5. S16 — 「1000万枚以上の一般画像で学習済み」が実態と合わない

ImageNet全体は約1400万枚ですが、事前学習に使われるILSVRC-1000クラスの学習セットは **約120万枚** です。同じスライドに「ImageNetの1000クラス分類」と併記しているため矛盾して見えます。

> **対応案**: 「約120万枚」または「大規模な一般画像」に修正。

「本セミナーで使用したノートブックとデータセット」＋GitHub URL が **「書籍」カードの枠内** に配置されています（書籍カードは y=1.20–2.90、当該テキストは y=2.07 / 2.41）。

## 🟢 軽微（余力があれば）

気付く受講者は限られますが、直すと精度が上がる箇所です。

### [ ] 8. S1 — 開催日「2026年6月27日」が現在（2026/8/28）より過去

再演であれば日付の更新が必要です。

### [ ] 9. S13 — 「1マス右にずれた」行列が実際にはシフトになっていない

元の行列を1列シフトしたものになっておらず、3列目が3行分ずれています。プーリング結果は偶然一致しますが、数字を突き合わせる受講者には気付かれます。

また **max pooling は厳密には平行移動不変ではありません**。見出しは「結果は同じ」より「**結果が変わりにくい**」が安全です。

### [ ] 10. S12 — 「明るい点を探す」フィルタは実際には平滑化フィルタ

`0 1 0 / 1 2 1 / 0 1 0` は **ぼかし（平滑化）フィルタ** です。キャプション「形全体がぼんやり残る」はぼかしの挙動そのものなので、見出しを「全体をならす」等に。輝点検出ならラプラシアン `0 -1 0 / -1 4 -1 / 0 -1 0` が適切です。「角を探す」フィルタも実質は斜め方向の検出です。

### [ ] 11. S20 — 交差検証の帯が3階調あり、凡例と対応が読み取れない

凡例は「薄い色＝検証／濃い色＝学習」の2階調ですが、図には中間色が混じっています（1回目の2本目、3回目の4本目）。2階調に統一を。

### [ ] 12. S23 — 「しきい値を下げる＝甘く判定」が現場語感と逆に読まれる

外観検査の現場では「甘く判定」＝製品を通しやすくする、と受け取られがちです。「**検出を増やす方向／減らす方向**」等の表現が安全。また1つ目の「見逃し↓」の矢印だけ淡色で視認性が低いです。

### [ ] 13. S4 — 目次2項目目だけフォントサイズ指定がない

「CNNの基礎知識」のみサイズ未指定（他は18pt）。環境によって崩れます。

### [ ] 14. S3 — 空のテキストシェイプが残っている

Text 9（0.98, 3.99 / 7.89×0.50）が中身なしで配置されたままです。

### [ ] 15. S2 — 講師プロフィールの【年齢】52歳

社外向けセミナーで必須の情報ではありません。掲載可否のご判断を。

### [ ] 16. 全29枚 — スピーカーノートが全スライド空

本文の8割が画像＝口頭補足が前提の構成です。少なくとも計算例（S11・S13）と評価指標（S21・S22）にはノートを入れておくと再演時に助かります。
