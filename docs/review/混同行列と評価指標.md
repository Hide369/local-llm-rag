# 混同行列（Confusion Matrix）と評価指標

混同行列（Confusion Matrix）は、機械学習の分類モデルが「どれくらい正しく予測できたか」を可視化するための集計表です。

予測結果と実際の正解データを比べることで、モデルがどのクラスで間違いやすいか（混同しているか）を把握できます。

---

## 4つの要素

2値分類（陽性 / 陰性）の場合、結果は以下の4パターンに分かれます。

| 略称 | 名称 | 内容 | 判定 |
| --- | --- | --- | --- |
| **TP** | True Positive（真陽性） | 実際も予測も「陽性」 | 正解 |
| **TN** | True Negative（真陰性） | 実際も予測も「陰性」 | 正解 |
| **FP** | False Positive（偽陽性） | 実際は陰性だが、予測は「陽性」 | 誤り（タイプ1のエラー） |
| **FN** | False Negative（偽陰性） | 実際は陽性だが、予測は「陰性」 | 誤り（タイプ2のエラー） |

これを表の形に並べたものが混同行列です。

| | 予測：陽性 | 予測：陰性 |
| --- | --- | --- |
| **実際：陽性** | TP（真陽性） | FN（偽陰性） |
| **実際：陰性** | FP（偽陽性） | TN（真陰性） |

---

## 混同行列から計算する主要指標

| 指標名 | 計算式 | 意味・使いどころ |
| --- | --- | --- |
| **正解率 (Accuracy)** | $\frac{TP + TN}{TP + FP + FN + TN}$ | 全体の中でどれだけ当たったか。データバランスが良い時に利用 |
| **適合率 (Precision)** | $\frac{TP}{TP + FP}$ | 「陽性」と予測した中で、実際に陽性だった割合。誤検知（FP）を減らしたい時（例：スパム判定） |
| **再現率 (Recall)** | $\frac{TP}{TP + FN}$ | 実際の陽性の中で、どれだけ見逃さずに検知できたかの割合。見逃し（FN）を防ぎたい時（例：病気診断、不正検知） |
| **F1スコア (F1-score)** | $2 \times \frac{Precision \times Recall}{Precision + Recall}$ | 適合率と再現率の調和平均。不均衡データでのモデル総合評価に利用 |

---

## なぜ正解率だけでは不十分か

正解率（Accuracy）だけでは、がん診断などの「陽性が極めて稀なデータ」で「すべて陰性」と予測するダメなモデルでも高得点になってしまいます。

そのため、混同行列を使って適合率や再現率を確認することが不可欠です。
