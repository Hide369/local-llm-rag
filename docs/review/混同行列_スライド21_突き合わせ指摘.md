## 修正点

### [ ] 1. S21 — 誤字「不良品が優先へ流れる」【中程度】

「見るべきは2つのミス」ブロック内の記述。

| 現状 | 正 |
| --- | --- |
| 見逃し（偽陰性：FN）／ 不良品が**優先**へ流れる → 損害が大きい | 不良品が**後工程**へ流れる（または「客先へ流れる」） |

> 画像内の文言のため、図の再生成が必要です。
> [CNN画像認識セミナー_レビュー.md](CNN画像認識セミナー_レビュー.md) の「誤字・脱字 3件」（S16「をを」／S12「ε」／S23「工程に」）に対する **4件目** にあたります。まとめて修正すると効率的です。

### [ ] 2. S21 — 「陽性＝不良品」の対応づけが明示されていない【中程度】

S21は「真陽性」「偽陰性」という漢字表記の中にしか陽性／陰性が現れず、**どちらのクラスを陽性として扱っているかの宣言がありません**。

医療診断や不正検知の文脈で混同行列を学んだ受講者は、「陽性＝良品では？」と誤解する余地があります（実際にレビュー中にこの疑問が出ました）。

**正しい規約**: 陽性（Positive）は「望ましい方」ではなく、**「検出したい対象が存在する方」** を指します。語源である医療検査でも、がん検査の「陽性」は「がんの疑いあり」＝悪い結果です。外観検査では検出対象が不良品なので、**陽性＝不良品** となります。

指標の意味から逆算しても確認できます。

- **再現率＝「見逃さずに検出できた割合」** … 見逃したくないのは不良品 → 陽性＝不良品
- **適合率＝「陽性と判定した中の正解率」** … 減らしたいのは良品への誤検知（FP） → 陽性＝不良品

仮に陽性＝良品とすると、**不良品の見逃しが FP 側に回り、評価から見えにくくなります**。

> **対応案**
> - S21に一行「※ ここでは『不良品』を陽性として扱います」を追記
> - `docs/混同行列と評価指標.md` に「陽性とは『検出したい対象』であり、望ましい方ではない」旨の注記を追加

### [ ] 3. S21 / S22 / md — F値の名称がバラバラ【軽微】

| 資料 | 表記 |
| --- | --- |
| S21 | F値（F1スコア） |
| S22 | F1 値 / F1 score |
| md | F1スコア（F1-score） |

実害はありませんが、同じセミナー内で3通りの呼び方が混在しています。いずれかに統一を推奨します。

### [ ] 4. S21 — F値の式に括弧がない【軽微】

S21の表記は `2×P×R / P+R`。スライド上は分数レイアウトで組まれているため投影時に誤読はしませんが、**板書や配布資料に一行で転記されると `2×P×R/P + R` と読まれる余地** があります。

> **対応案**: `2 × (Precision × Recall) / (Precision + Recall)` の形で括弧を明示する。

## 参考：突き合わせの根拠

### 4要素の対応（すべて一致）

| md（一般） | S21（外観検査） | 件数 |
| --- | --- | --- |
| TP 真陽性：実際も予測も陽性 | 正しく検出（真陽性：TP） | 45件 |
| TN 真陰性：実際も予測も陰性 | 正しく合格（真陰性：TN） | 930件 |
| FP 偽陽性：実際は陰性だが予測は陽性 | 誤検知（偽陽性：FP） | 20件 |
| FN 偽陰性：実際は陽性だが予測は陰性 | 見逃し（偽陰性：FN） | 5件 |

行列の並びも完全一致（行＝実際、列＝予測、左上TP・右上FN・左下FP・右下TN）。S22右下の「混同行列のイメージ」とも同じ向きです。

### 指標の対応

| 指標 | md | S21 | 判定 |
| --- | --- | --- | --- |
| 適合率 Precision | $TP/(TP+FP)$ | 45/(45+20) = 69.2% | ✅ 式・値とも一致 |
| 再現率 Recall | $TP/(TP+FN)$ | 45/(45+5) = 90.0% | ✅ |
| F1 | $2(P \times R)/(P+R)$ | 78.3% | ✅ 検算 78.2% ≒ 78.3% |
| 正解率 Accuracy | $(TP+TN)/(TP+FP+FN+TN)$ | **S21には無い** → S22に (45+930)÷1000 = 97.5% | ✅ 定義は一致 |

### 数値の整合（すべて破綻なし）

- 50 + 950 = 1000
- 45 + 5 = 50（実際の不良品）
- 20 + 930 = 950（実際の良品）
- 不良率 50 ÷ 1000 = 5%

### 「陽性＝不良品」の数値による裏付け

| | 陽性＝不良品（スライドの解釈） | 陽性＝良品（仮定） |
| --- | --- | --- |
| TP | 45 | 930 |
| FN | 5 | 20 |
| FP | 20 | 5 |
| TN | 930 | 45 |
| 適合率 | 45/(45+20) = **69.2%** | 930/935 = 99.5% |
| 再現率 | 45/(45+5) = **90.0%** | 930/950 = 97.9% |

スライドに記載されているのは 69.2% / 90.0% であるため、**陽性＝不良品で計算されていることが数値から確定**します。

## 参考：内容の過不足

### mdにあってS21に無いもの

- **正解率（Accuracy）** — スライドはS22に分けている。mdは4指標を1枚にまとめた形
- **「タイプ1のエラー / タイプ2のエラー」** — デック全体を通して一度も登場しない。G検定等で問われる用語のため、mdを補助資料として配る価値あり
- **「陽性／陰性」という語そのもの** — 上記 修正点2 を参照
- **「なぜ正解率だけでは不十分か」の説明** — S21には無し。S22の「注意：全部『良品』と答えても95%になってしまう」が対応しており、mdの「がん診断」例と同じ主旨

### S21にあってmdに無いもの

- **具体的な数値例**（1000件のケース）。mdは式のみ
- **FN/FPの業務インパクトの言語化**：見逃し → 損害が大きい／誤検知 → 手間とコストが増える
- **「どちらが痛いかは業務次第」** ＝ しきい値調整の論点（S23へ接続）
- 使いどころの例示分野の違い：md ＝ スパム判定・病気診断／スライド ＝ 外観検査
