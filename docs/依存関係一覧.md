# 依存関係一覧（インストールが必要なもの）

本システムを動かすために必要なものを、pipパッケージ・Ollamaモデル・自動取得モデル・
DB・環境変数の順にすべて挙げる。調査日: 2026-09-02（コード・`pip list`・`ollama list` を実測）。

依存の正は [requirements.txt](../requirements.txt)（バージョン固定）と本書（用途と使用箇所）である。
パッケージを追加・削除したら両方を更新すること。

## 3. Ollamaモデル（`ollama pull`）

| モデル | 役割 | 必須度 |
| --- | --- | --- |
| `bge-m3` | **埋め込み**（1024次元。[ingest/embedder.py](../ingest/embedder.py) にハードコード） | 必須 |
| `qwen2.5:7b-instruct` | 生成LLM（UIの既定値） | 必須 |
| `llama3.1:8b` | 生成LLM（UIの選択肢） | 任意 |
| `gpt-oss:20b` | 生成LLM（UIの選択肢） | 任意 |
| `qwen3:32b` | 生成LLM（UIの選択肢） | 任意 |
| `qwen2.5vl:7b` | **VLM**。`--with-vlm` またはUIのチェックボックスで図表を説明文にする | VLM使用時 |

- 生成モデルの一覧は [rag_chat_app.py](../rag_chat_app.py) の `MODELS`。ここに無いモデルはUIから選べない。
- VLMは環境変数 `OLLAMA_VLM_MODEL` で上書きできる（[ingest/vlm.py](../ingest/vlm.py)）。
- 埋め込みモデルを変えると次元が変わり既存のコレクションが使えなくなる。差し替えるなら
  `EMBED_DIM` と `COLLECTION_NAME` を合わせて変更し、全ファイルを再取り込みすること。
- `nomic-embed-text` は教材 `udemy3.py`（コレクション `local_docs`）用であり、本システムは使わない。

## 4. 自動ダウンロードされるモデル（`ollama pull` 不要）

| モデル | 役割 | 取得元・保存先 |
| --- | --- | --- |
| `onnx-community/bge-reranker-v2-m3-ONNX`<br>（`onnx/model_int8.onnx` + `tokenizer.json`） | **リランカー**（クロスエンコーダ、INT8量子化） | HuggingFace Hub。初回のみ約570MB・約1分。`~/.cache/huggingface/hub` |
| `japan_PP-OCRv4_rec_mobile` ほか検出/認識モデル | **OCR**（日本語） | RapidOCRが初回の画像ページ処理時に自動取得 |

ネットワークが要るのは初回取得時だけで、以降は完全にオフラインで動く。

## 5. DB

ChromaDBを**組み込み（PersistentClient）**で使う。サーバの別途インストール・起動は不要。

- 保存先: `chroma_db/`
- コレクション名: `local_docs_v2` / 距離: `cosine`（[ingest/store.py](../ingest/store.py)）
- BM25側は外部依存のない自前実装（[ingest/lexical.py](../ingest/lexical.py)）で、追加インストールは不要

## 6. 環境変数（`.env`）

`.env.example` を `.env` にコピーする。ローカルのOllamaだけで使うなら**すべて空のままで動く**。

| 変数 | 用途 |
| --- | --- |
| `OLLAMA_HOST` | 標準ポート以外、またはColabのL4 GPUに接続するときだけ設定する |
| `OLLAMA_API_KEY` | Colab側のリバースプロキシの認証キー |
| `OLLAMA_VLM_MODEL` | VLMを差し替えるとき（既定 `qwen2.5vl:7b`） |

## 7. （任意）ColabのL4 GPUに接続する場合

[colab/run_ollama_server.ipynb](../colab/run_ollama_server.ipynb) を実行するColab側で追加で必要なもの。

- apt: `zstd` `pciutils` `lshw`
  （`pciutils`/`lshw` が無いとOllamaのインストーラがGPUを検出せず、CPU動作になる）
- Ollama本体（`curl -fsSL https://ollama.com/install.sh | sh`）と上記モデル一式
- pip: `fastapi` `uvicorn[standard]` `httpx` `pyngrok`
- ngrokの無料アカウントとauthtoken

詳しい手順はREADMEの「ColabのL4 GPUに接続する」を参照。
