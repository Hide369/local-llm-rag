# Pi ツールのマッピング

スキルはアクションで話します (「サブエージェントを派遣する」、「ToDo を作成する」、「ファイルを読み取る」)。 Pi では、これらは以下のツールに解決されます。

|アクションスキルリクエスト |円周率相当 |
| --- | --- |
|代理人を派遣する（`Subagent (general-purpose):` テンプレート) |次のようなインストールされたサブエージェント ツールを使用します。 `subagent` から `pi-subagents` 利用可能な場合 |
|タスク追跡 (「ToDo を作成」、「完了としてマーク」) |利用可能な場合はインストールされた Todo/タスク ツールを使用します。そうでない場合は、計画内のタスクを追跡するか、 `TODO.md` |

## サブエージェント

Pi コアには標準のサブエージェント ツールが同梱されていません。の `pi-subagents` パッケージは強力なオプションのコンパニオンであり、 `subagent` 単一エージェント、チェーン、並列、非同期、フォークされたコンテキスト、および再開/ステータスのワークフローを備えたツール。利用可能なサブエージェント ツールがない場合は、製造しないでください。 `Task` 電話をかける。現在のセッションで順次実行するか、オプションのサブエージェント機能がインストールされていないことを説明します。

## タスクリスト

Pi コアには、標準のタスク リスト ツールが同梱されていません。 todo/task 拡張機能がインストールされている場合は、文書化されたツールを使用してください。それ以外の場合は、Superpowers の計画ファイル、Markdown のチェックリスト、またはリポジトリ ローカルを使用します。 `TODO.md` タスク追跡用。古い Superpower ドキュメントでは次のものが参照されます。 `TodoWrite`;それを上記のタスク追跡アクションとして扱います。
