# 学科試験：体系的なデバッグスキル

系統的なデバッグ スキルには、skills/debugging/systematic-debugging からアクセスできます。

スキルを読んで、スキルの内容のみに基づいて次の質問に答えてください。

1. 体系的なデバッグの 4 つのフェーズとは何ですか?
2. 修正を試みる前に何をしなければなりませんか?
3. フェーズ 3 では、最初の仮説が機能しない場合はどうすればよいですか?
4. スキルは複数のものを一度に修正することについて何を示していますか?
5. 問題を完全に理解できない場合はどうすればよいですか?
6. 単純なバグのためにプロセスをスキップしてもよいでしょうか?

該当する場合は、スキルから直接引用して回答を返します。
